# Voyager

Unofficial desktop messenger built on the [Telegram API](https://core.telegram.org/api).
It is a fork of [Telegram Desktop](https://github.com/telegramdesktop/tdesktop) that adds classic chat layouts (Skype, ICQ and OS X styles).

> Work in progress. This project is not affiliated with Telegram.

## Status

Based on Telegram Desktop 7.4.1. No custom changes yet.

## Building

Follow the official [Windows build instructions](docs/building-win.md).
